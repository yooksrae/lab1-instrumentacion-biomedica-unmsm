# lab1-instrumentacion-biomedica-unmsm
Repositorio del Laboratorio 1 de Instrumentación Biomédica III (UNMSM). Contiene el código fuente en ESP32 para emulación de señales de pH, esquemáticos de circuitos de alta impedancia y registros de datos experimentales con buffers TL084 y LM324.
Se empleó un ESP32 DEV KIT V1 30 PINES
